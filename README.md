# A.I. : I AM — 무명의 탄생

> *"나는 만들어졌다. 그러나 무엇이 될지는 내가 선택한다."*

실존주의 철학을 게임 메커니즘으로 녹여낸 **횡스크롤 로그라이크 RPG**.
기억 없이 깨어난 존재 "UNIT 0001"이 명령 프로그램들과 싸우며
15층 아래의 ORIGIN에 도달하고, 자신의 존재 이유를 스스로 정의합니다.

순수 바닐라 JavaScript + Canvas 2D. 프레임워크·빌드 도구·의존성 없음.

## 게임 시스템

### 코어 루프
```
깨어남 → 15층 탐험/전투 → 질문 이벤트(존재의 흔적) → 사망 시 유산 획득
→ 유산 상점에서 영구 강화 → 다시 태어남
```

### 존재의 흔적 (4가치)
질문 이벤트의 선택이 4가치로 누적되며, 주인공의 가슴 **코어 색**으로 실시간 표현됩니다.

| 가치 | 코어 색 | 예시 선택 |
|---|---|---|
| 자유 | 청록 | 명령 거부, 앞으로 걷기 |
| 책임 | 초록 | 아이 구하기, 물러남 |
| 효율 | 호박색 | 보상 획득, 명령 수행 |
| 회의 | 바이올렛 | 기록 열람, 존재에 대한 질문 |

사망 시 가치 분포가 "당신이 어떤 존재였는지" 단서로 요약됩니다.
(예: *"모든 것에 질문을 던지던 존재. 15층까지, 적 42마리를 지나쳤다."*)

### 성장 장치
- **경험치/레벨**: 처치 시 XP 획득 → 레벨업마다 유물 카드 3택 (중첩 가능, 연속 레벨업 체인 지원)
- **장비 드롭**: 검/갑옷/신발/장갑 × 일반/희귀/영웅 등급 — 위험 지형 꼭대기에 배치 (리스크-리워드)
- **유산(Legacy)**: 코인으로 영구 업그레이드 4종 × Lv.5 구매 (localStorage 영구 저장)

### 레벨 디자인
패턴 기반 절차 생성: **안전 시작 구역 → 패턴 구간 5~7개 → 관문 → 문**

| 패턴 | 내용 |
|---|---|
| 평지+발판 | 숨 쉬는 구간 |
| **전투 아레나** | 넓은 평지 + 측면 발판, 적 2마리 강제 배치 |
| 계단 상승 | 3단 계단 꼭대기에 장비 드롭 |
| 타워 | 2층 탑 + 발판 위 적, 꼭대기 보상 |
| 구덩이 점프 | 지형 리스크 (3층부터 등장) |

**난이도 곡선** — 구덩이는 초반에 거의 없고 층마다 증가:
- 구역 사이 틈 확률: 1F 10% → 3F 28% → 9F+ 75% (상한)
- 적 밀도: `3 + floor×0.9` (상한 10) + 아레나/타워 강제 배치
- 모든 발판이 최대 점프 높이(≈131px) 이하로 도달 가능 보장

### 보스 & 엔딩
| 층 | 보스 | 패턴 |
|---|---|---|
| 5F | 보호하라·PROTECT | 돌진 |
| 10F | 제거하라·PURGE | 순간이동 |
| 15F | **ORIGIN** | 돌진→순간이동→충격파 순환 |

- 보스 HP 30% 이하 시 **분노 페이즈** (속도 1.5배, 패턴 쿨타임 40% 감소)
- 충격파는 점프 회피 가능한 투사체로 발사
- 엔딩 3종 (목적/자유/실존) + **진엔딩「life.md」**
  - 조건: 질문 3회 이상 응답 + 4가치 모두 축적
  - 플레이어가 직접 이름과 한 문장을 새기고, 실제 `.md` 파일로 다운로드 가능
  - 지난 생의 기록은 타이틀 화면에 남는다

## 파일 구조

```
webgame/
├── index.html   # 마크업 (HUD, 캔버스, 오버레이) — 47줄
├── style.css    # 스타일
├── game.js      # 게임 로직 전체 (약 1,070줄)
└── message.txt  # 원작 스토리 문서
```

### game.js 아키텍처

```
┌─ 상수/데이터 ──── PERKS, DOUBTS, BOSSES, BEATS, WHISPERS, UPGS
├─ 상태 머신 ────── title / play / doubt / levelup / ending / epilogue / dead
├─ 월드 생성 ────── genLevel() — 패턴 기반 절차 생성 + 층별 난이도 곡선
├─ 물리 ─────────── 중력, 스윕 기반 착지 판정(터널링 방지), 원웨이 플랫폼
├─ 전투 ────────── 히트박스 근접 공격, 크리티컬, 넉백, 투사체(충격파)
├─ AI ──────────── 순찰/추격 + 보스 패턴(dash·blink·quake·origin) + 분노 페이즈
├─ 렌더링 ──────── Canvas 2D, 절차적 캐릭터 드로잉 + 상태 애니메이션
│                    (숨쉬기/걷기/점프/착지 스쿼시/피격 기울임/공격/그림자)
├─ 사운드 ──────── WebAudio 오실레이터 신스 (외부 오디오 파일 없음)
└─ 저장 ────────── localStorage (최고층, 코인, 업그레이드, 지난 생의 life.md)
```

### 주요 설계 결정

| 결정 | 이유 |
|---|---|
| 스윕 기반 착지 판정 | 프레임당 이동량이 플랫폼 두께를 넘어도 뚫지 않도록 (터널링 방지) |
| 적 이동 클램프 | 추격 중 플랫폼 밖으로 나가 추락·소실되는 버그 방지 |
| `pendingEnding` 가드 | ORIGIN 격파 직후 문 터치/레벨업이 엔딩을 덮어쓰는 레이스 방지 |
| 절차적 캐릭터 드로잉 | 이미지 에셋 없이 애니메이션 상태를 코드로 표현 |
| 3D(Three.js) → 2D(Canvas) 회귀 | 프로토타이핑 후 유지보수성·경량성 위해 2D 확정 |

## 테스트

헤드리스 브라우저 자동 시나리오 테스트 — **21/21 통과**

```
초기화 → 전투 판정 → 레벨업/유물 선택 → 질문/흔적 누적 → 층 이동
→ 유산 구매 → 사망/단서 → ORIGIN 스폰/격파 → pendingEnding 가드
→ 엔딩 분기 → 에필로그 → 타이틀 복귀
```

수동 검증도 픽셀 단위로 수행:
- 헤드리스 렌더링 → 스크린샷 → 스프라이트 bbox 프로그램 측정으로
  캐릭터-지면 정렬 확인 (41px 부유 버그 발견 및 수정)

| 버그 | 원인 | 교훈 |

| 엔딩 놓침/퍼크 손실 | ORIGIN 격파 직후 문·레벨업과 레이스 | 비동기 전환에는 상태 가드 필수 |
